Cara 1: Instalasi Manual (Via Terminal)

Metode ini disarankan untuk pengguna yang familiar dengan command line Linux (Ubuntu/Debian).

1. Persyaratan Sistem

  • Node.js: Versi 18.x atau lebih baru.
  • PostgreSQL: Database utama.
  • PM2: Process manager.

2. Install Dependensi

# Masuk ke direktori project
cd bn

# Install dependensi
npm install

3. Konfigurasi Environment (.env)

Buat file .env di root project. Sesuaikan kredensial database:

DB_HOST=localhost
DB_PORT=5432
DB_USER=trader
DB_PASSWORD=Rahasia25@
DB_NAME=trading

NEXTAUTH_URL=http://your-domain.com
NEXTAUTH_SECRET=your-secret-key
NODE_ENV=production

4. Setup Database Manual

sudo -u postgres psql
CREATE USER trader WITH PASSWORD 'Rahasia25@';
CREATE DATABASE trading OWNER trader;
GRANT ALL PRIVILEGES ON DATABASE trading TO trader;
\q

Lalu restore data:

./restore-database.sh backups/backup-terbaru.sql

5. Deployment Manual

# Build & Start
npm run build
pm2 start npm --name "next-app" -- start
pm2 start npm --name "worker" -- run worker
pm2 save

Cara 2: Instalasi Mudah (Via aaPanel)

Direkomendasikan untuk Pemula! Metode ini menggunakan Control Panel visual (seperti cPanel) sehingga Anda tidak perlu banyak mengetik kode.
PENTING: Gunakan VPS yang masih KOSONG (Fresh Install). Jangan install aaPanel di VPS yang sudah ada websitenya karena akan menyebabkan error.

Langkah 1: Install aaPanel

Login ke VPS Anda via SSH (Putty/Terminal) satu kali saja untuk menginstall panel:

# Untuk Ubuntu/Deepin
wget -O install.sh http://www.aapanel.com/script/install-ubuntu_6.0_en.sh && sudo bash install.sh aapanel

Setelah selesai, terminal akan menampilkan URL, Username, dan Password. Simpan data ini!

Langkah 2: Login & Install Software

  1. Buka URL aaPanel di browser Anda.
  2. Login dengan username/password yang diberikan.
  3. Saat pertama kali login, pilih paket LNMP (Recommended).
  4. Buka menu App Store dan install aplikasi berikut:
    • Node.js Version Manager (Pilih Node v18/v20).
    • PostgreSQL Manager (Versi 14/15).
    • PM2 Manager.

Langkah 3: Upload File Project

  1. Buka menu Files di aapanel.
  2. Masuk ke folder /www/wwwroot/.
  3. Klik tombol Upload dan upload file project Anda (sebaiknya dalam bentuk .zip).
  4. Klik kanan file .zip lalu pilih Unzip.

Langkah 4: Setup Database (Visual)

  1. Buka menu Databases > PostgreSQL.
  2. Klik Add Database.
  3. Isi DB Name (misal: trading), User (misal: trader), dan Password.
  4. Setelah dibuat, klik tombol Tools atau Import untuk mengupload file backup .sql Anda.

Langkah 5: Jalankan Aplikasi (Node.js)

  1. Buka menu Website > Node Project.
  2. Klik Add Node Project.
  3. Project Path: Pilih folder project yang sudah di-unzip tadi.
  4. Start Command: npm run start (pastikan sudah dibuild) atau next start.
  5. Port: 3000.
  6. Klik Submit. Aplikasi akan otomatis berjalan!

Langkah 6: Jalankan Worker

Untuk worker, Anda bisa menambahkannya di PM2 Manager secara manual atau jalankan script npm run worker melalui terminal bawaan aaPanel.

Troubleshooting

Error Koneksi Database

Pastikan nama database, user, dan password di file .env sama persis dengan yang Anda buat di PostgreSQL/aaPanel.

Aplikasi Error 502 Bad Gateway

Ini artinya aplikasi Node.js mati atau restart. Cek log:

pm2 logs

Worker tidak terhubung ke Binance

Pastikan port outgoing 443 terbuka di Firewall provider VPS Anda (AWS/Google Cloud/DigitalOcean biasanya memblokir beberapa traffic, tapi Port 443 biasanya aman).
